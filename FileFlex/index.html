How it works

  1. Select or drop files. Images are optimized via canvas. Other files use browser gzip for size-down; original type is retained when boosting.
  2. Choose your target size in KB and mode.
  3. Click Process to optimize. Download the processed bundle or individual files from the list.

Processing happens locally in your browser. For heavy audio/video transcoding, a server-side encoder is recommended.
